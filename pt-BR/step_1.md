## O que você vai fazer

Use as ferramentas de reconhecimento facial do Scratch Lab para criar um jogo de morder queijo que você pode jogar com a boca!

Você precisará de uma **webcam** para concluir este projeto.

![Um jogo no Scratch com uma tigela flutuante de cheesy puffs na frente de uma imagem de webcam de uma mulher de meia idade com a boca aberta.](images/whatyouwillmake.png)

## título: Onde minhas imagens estão armazenadas?

- Este projeto usa uma tecnologia chamada "aprendizado de máquina". Os sistemas de aprendizado de máquina são treinados usando uma grande quantidade de dados. O sistema de aprendizado de máquina usado neste projeto já foi treinado usando um grande número de fotos, e as suas imagens não serão usadas para treiná-lo.
- Nenhuma imagem da sua câmera é enviada para este site ou qualquer outro site.
